# opencitystudio.ru

Публичный статический сайт OpenCity Studio и серийного цифрового комикса
«Город Нейросеть».

Сайт не требует сборки: GitHub Actions публикует содержимое корня репозитория
в GitHub Pages. Канонический адрес — <https://opencitystudio.ru>.

Профили героев и другие содержательные данные не редактируются в HTML. Их источник
истины находится в `projects/open-city/canon/` репозитория `open-city`, откуда
производные страницы синхронизируются сборщиком. В частности,
`characters/index.html` и `assets/styles.css` — сгенерированные файлы.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер.
