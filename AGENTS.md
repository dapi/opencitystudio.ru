# Инструкции для автоматизации

## Работа с Git

- По умолчанию работайте непосредственно в ветке `main`.
- Не создавайте новые ветки и pull request, если пользователь прямо об этом не попросил.
- Перед коммитом проверяйте состав изменений и результаты доступных проверок.
- Не включайте в коммит посторонние изменения без явного подтверждения пользователя.
